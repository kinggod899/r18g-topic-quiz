# R18G 题材定位问卷

用「坐标」而非「标签」定位黑暗题材偏好的问卷工具。
**68 个题材 · 62 个钩子 · 7 根轴**，纯前端，单文件，无需后端。

直接打开 [`index.html`](index.html) 即用，数据不上传、不保存。

## 为什么不用「你喜欢哪个题材」直接问

那个问题没人答得出真话——人会挑自己觉得有品位的黑暗，避开让自己真的不适的，
而后者往往才是真正的点。所以改成三层间接测量：

1. **不问题材，问轴。** 题材是表面，七根轴是底下的力。同一个人勾「献祭」和勾「产房」，
   可能是同一根轴在响。
2. **不问喜欢，问「哪几样让你坐直」。** 钩子是具体画面，不是概念。具体画面能唤起反应，概念不能。
3. **先划禁区，再算偏好。** 踩雷权重是命中钩子的 3.5 倍。

## 七根轴

| 轴 | 含义 |
|---|---|
| 权力落差 | 上位者可以毫无代价地处置下位者 |
| 身体越界 | 内脏、骨骼、器官、切割——身体不再完整 |
| 羞辱亲密 | 羞耻本身就是最深的亲密 |
| 意识剥夺 | 被使用者的内在被抹掉，或反过来吞掉使用者 |
| 死亡在场 | 尸、濒死、下葬、腐朽——死的重量压在活人身上 |
| 秩序崩解 | 公开、围观、律法失效、看客的沉默 |
| 题材位置 | 文体与视角本身就是快感来源 |

## 打分

题材在各轴上带权重（-2..2），按作答加权：

- 主轴 ×3.0，副轴 ×1.5，其余正权重 ×0.5
- 钩子每命中一个 +2
- 硬禁区每条 −7，且整题材剔除（结果页单列，供回头松边界）
- 软偏好把对应轴压到 45%（命中 1 条）或 20%（2 条以上）

## 改题库

数据源只有两处，网页与命令行共用：

```bash
python r18g_quiz.py            # 命令行跑问卷
python r18g_quiz.py list       # 打印全表
python r18g_quiz.py topic 12   # 看第 12 个题材
python 导出谱系.py              # 刷新 题材谱系.md
python build_site.py           # 重新生成 index.html
```

加一个题材：在 `TOPICS` 里补 `axes` 与 `hooks`，再到 `题材解释.py` 补一条解释，
重跑 `build_site.py`。

## 作品推荐

每个题材可以挂若干部参考作品，数据在 `作品推荐.py`，结构：

```python
"RUIN_WIFE": [
    {
        "title": "铁男",
        "origin_title": "鉄男 TETSUO",
        "author": "塚本晋也",
        "year": 1989,
        "type": "film",      # film / novel / manga / game / art / other
        "note": "身体被异物侵入后一点点不再是人的过程，全片用黑白和金属噪音堆出来。",
        "tags": ["日本", "身体恐怖"],
        "link": "",          # 可空
    },
],
```

`origin_title`、`author`、`year`、`note`、`tags`、`link` 都可以留空，
留空的部分不会渲染。没有合适作品的题材保持空列表 `[]`，页面上就不显示这一栏。

约定：只放已公开出版或发行的作品，`note` 写具体点，别写「很经典」。

写完后重跑 `python build_site.py`，网页会同时更新结果页和题材全谱两处。

## 几个刻意的拆分

**失禁拆成三项。** 原先把三件事捆在一条钩子里，导致勾一条「排泄」禁区会误杀 16 个题材。
现拆为 `体液`、`活人失禁`、`死后失禁·尸水`。产后血水、哺乳、溺水不再被误伤。

**尸体和腐烂拆开。** 一个是刚死的身体还能用，一个是时间已经把它改成了别的东西。
混在一条禁区里，讨厌腐烂的人会连带排除《荒年》《身体编年》这类根本没有尸体的题材。

**不追求覆盖全部标签。** 68 是「能互相区分」的数量，不是穷举。
两个题材描述同一件事就不该分成两条。
