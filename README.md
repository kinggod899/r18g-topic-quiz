# R18G 题材定位问卷

一个用「坐标」而非「标签」来定位黑暗题材偏好的问卷工具。
**68 个题材 · 62 个钩子 · 7 根轴**，纯前端，单文件，无需后端。

> 这是一个创作前的选题工具，不是内容库。它输出的是「往哪个方向写」，
> 而不是作品本身。所有条目为抽象分类与写作方法论。

## 使用

直接打开 [`index.html`](index.html) 即可，无需安装任何东西。
所有数据留在本机浏览器里，不上传、不保存。

## 为什么不用「你喜欢哪个题材」直接问

那个问题没有人答得出真话——人会挑自己觉得有品位的黑暗，避开让自己真的不适的，
而后者往往才是真正的点。所以改成三层间接测量：

1. **不问题材，问轴。** 题材是表面，七根轴是底下的力。同一个人勾「献祭」和勾「产房」，
   可能是同一根轴在响。
2. **不问喜欢，问「哪几样让你坐直」。** 钩子是具体画面，不是概念。具体画面能唤起反应，概念不能。
3. **先划禁区，再算偏好。** 踩雷权重是命中钩子的 3.5 倍。宁可错杀一个匹配，
   也不要给出一个读到一半想关掉的东西。

## 七根轴

| 轴 | 含义 |
|---|---|
| 权力落差 | 上位者可以毫无代价地处置下位者 |
| 身体越界 | 内脏、骨骼、器官、切割——身体不再完整 |
| 羞辱亲密 | 羞耻本身就是最深的亲密 |
| 意识剥夺 | 被使用者的内在被抹掉，或反过来吞掉使用者 |
| 死亡在场 | 尸、濒死、下葬、腐朽——死的重量压在活人身上 |
| 秩序崩解 | 公开、围观、律法失效、看客的沉默 |
| 题材位置 | 文体与视角本身就是快感来源 |

## 打分

题材在轴上带权重（-2..2），按你的作答加权：

- 主轴 ×3.0，副轴 ×1.5，其余正权重 ×0.5
- 钩子每命中一个 +2
- 硬禁区每条 −7，且整题材剔除（会在结果页单列，供你回头松边界）
- 软偏好把对应轴压到 45%（命中 1 条）或 20%（2 条以上）

## 文件

| 文件 | 作用 |

| `index.html` | **网页本体**，自包含单文件（约 94 KB），GitHub Pages 直接发布这个 |

## 自己改题库

数据源只有两处，网页与命令行共用：

```bash
python r18g_quiz.py            # 命令行跑问卷
python r18g_quiz.py list       # 打印轴 / 钩子 / 题材全表
python r18g_quiz.py topic 12   # 看第 12 个题材的细分
python 导出谱系.py              # 刷新 题材谱系.md
python build_site.py           # 改了数据后重新生成 index.html
```

加一个题材：在 `r18g_quiz.py` 的 `TOPICS` 里补一个 `axes` 与 `hooks` 的字典，
再到 `题材解释.py` 里补一条解释，重跑 `build_site.py` 即可。

## 题材库的来源

题库不是凭感觉列的，主要依据：

- **pixiv 百科**的 R-18G / リョナ / 欠損 / 腹パン / impaled / 首絞め 等词条——判定标准与基础分支
- **F-List 社群的 kink 词表**（Gore/Torture/Death、Vore & Unbirth、Inflation、Watersports & Scat 等分区）——英文侧定义与边界
- **凪常サツキ《リョナという特殊性癖について》**（カクヨム）里的「特殊性癖小览」——最系统的一份 ryona 属性表，含腹パン、皮はぎ、串刺し、箱姦、凍死、奇形、hemicorporectomy、嘔吐、爪剥ぎ、拡張、麻酔等条目
- 处刑史、外科史、畸形秀史等一手材料——「技术上到底怎么做的」

## 一些刻意的设计

**失禁拆成三项。** 原本一个「体液 / 失禁」把三件事捆在一起，导致勾一条「排泄」禁区
就会误杀 16 个题材。现拆为 `体液`（汗/泪/分泌/奶水/羊水）、`活人失禁`、`死后失禁·尸水`。
产后血水、哺乳、溺水不再被误伤；绞刑后的失禁归入死亡一侧。

**尸体和腐烂拆开。** 一个是刚死的身体还能用，一个是时间已经把它改成了别的东西。
原先把两者绑在一条禁区里，讨厌腐烂的人会连带排除《荒年》《身体编年》这类根本没有尸体的题材。

**不追求覆盖全部标签。** 68 个是「能互相区分」的数量，不是穷举。
两个题材如果描述的是同一件事，就不该分成两条。

## 声明

本工具只做题材分类与写作方法论，不含具体情节文本。所有条目均为抽象概念，
用于创作前的方向定位。虚构内容与现实无关。
